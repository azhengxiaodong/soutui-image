# 审图规则发布与客户端更新方案

状态：已实现并按登记范围完成本机验收。最终程序为 `0.2.1`，规则仍为 `2026-10-29.5`。本轮只接入私有分发、版本绑定和程序升级，没有修改审核文字、调用新云端审图或生成新图片。另一台真实电脑尚未验收。

## 已发布的更新源

私有仓库：[wanghua361/soutui-image-updates](https://github.com/wanghua361/soutui-image-updates)。稳定规则发布为 `rules-2026-10-29.5`，最终程序发布为 [app-0.2.1](https://github.com/wanghua361/soutui-image-updates/releases/tag/app-0.2.1)，签名清单序号为3。测试预发布只用于传输验证，不进入默认稳定通道。旧版本保留为历史，不覆盖已有版本资产。

维护电脑负责验证和发布，GitHub负责分发。其他电脑获取已发布规则时不需要维护电脑保持开机，也不需要另建服务器。该私有仓库不存储商品图片、网站会话、模型日志或运行记录。

## 软件如何更新

1. 主程序使用Python管理网站接口、图片处理、Codex调用、九组任务及保存。
2. 规则包仅包含引擎已支持的声明式规则和提示词。客户端校验白名单字段、版本、内容SHA-256、维护端Ed25519签名及引擎兼容性，不执行远程Python代码。
3. 目标电脑首次通过“只读授权”配置仓库读取令牌。以后启动或手动点击“检查规则更新”时同步并缓存规则，不为每张图片访问GitHub。
4. 每款商品绑定原图SHA-256及实际规则版本与哈希。九组、后台线程和全部补生使用同版；新商品选最新兼容稳定版，已有生成历史的商品继续原版本。
5. 审核记录与缓存绑定实际规则身份，不复用其他规则的通过结论。旧图升级需明确复核操作，不在启动更新时把所有历史图片重新送审。
6. 普通断网、损坏包或验签失败保留可用旧版本并显示状态。最新签名清单明确撤销的规则会阻断继续使用，即使其替代规则暂不兼容当前引擎。

提示词等引擎已支持的内容可以仅更新规则包。新裁剪算法、新模型接入、新工具、依赖、界面或网站操作变化需要程序升级，不能只在JSON中写入新步骤就让旧引擎执行。

## 程序升级

程序和规则分开发布。软件获取签名清单后，可通过“程序升级”下载新ZIP，在任务暂停或结束后由独立副本替换并重启。下载内容需验证签名描述和完整哈希，解包检查路径边界。旧程序保留备份，本机运行记录保留。源码运行不使用exe替换入口。

遇到新规则不兼容时保留原兼容版本，同时保留最新清单中的程序升级信息。已安装当前版本时不重复提供同版升级。此机制减少逐台发包；初次安装仍需分发完整软件，未来环境变化也可能需要单独处理。

## 账号与发布权限

维护机使用已有GitHub登录发布；签名私钥由Windows DPAPI加密保存在本机，不上传、不打包。客户端只通过GET读取固定仓库，使用仅对该仓库授权Contents Read-only的令牌；令牌在各机用DPAPI保护，到期或撤销后重新配置。目标电脑不需要安装Git。

每台电脑仍需自己的Codex登录、生图网站登录和可用额度。GitHub不运行审图模型。规则更新属于审核指令和流程的版本分发，不代表训练了模型或证明识别准确率提升。

## 实际验收与限制

- `U_RULES`：35份实际原图/结果记录、49个已完成整图阶段的提示词哈希一致，定位和扣位阶段文字一致。
- `U_GITHUB`：真实私有仓库发布与下载、匿名访问被拒、两版本传输、签名和损坏包拒绝、旧任务固定与本地离线读取。
- `U_E_RUNTIME`及`U_PIPELINE`：复用真实已完成审核证据，验证线程规则传递、不同版本缓存隔离、九目录保存和原任务/轮次保留；未新增模型调用。
- `U_PRIVATE_CLIENT`：0.2.1真实私有Release下载回读、exe身份与ZIP哈希、本机GUI和暂停续跑、解压迁移及真实两版程序目录替换通过。原两款合格数保持10张/1张，第一款组09仍因原三轮补生上限暂停。
- 108项代码检查通过；最终冻结文件SHA-256检查通过。证据及各阶段哈希见 `validation/updates/release_acceptance.json`、`validation/frozen_modules.json`和`docs/模块验收记录.md`。

真实下载使用本机维护账号授权的GET客户端，未复制令牌到验证目录。目标电脑的细粒度只读令牌首次配置、浏览器兼容及完整业务尚需现场验收。本机不同目录的迁移不能代替另一台电脑验收；此次更新验证也不能代替新一轮视觉准确率测试。第二款其余八组及店铺上传的未完成范围继续保留。

维护命令与首次授权步骤见 [私有更新维护说明](./私有更新维护说明.md)，用户操作见 [Windows版使用说明](./Windows版使用说明.md)。
