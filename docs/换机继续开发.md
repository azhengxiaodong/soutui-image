## 另一台Windows电脑的准备

安装Git和Python 3.11或更新版本后，在打算存放项目的目录运行：

```powershell
git clone https://github.com/wanghua361/soutui-image.git
cd soutui-image
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -B tools/check_frozen.py
.\.venv\Scripts\python.exe -B tools/run_checks.py
```

冻结检查使用原始文件SHA-256；仓库已禁止换行自动转换。若检查失败，先查明本地文件变化，不得直接更新冻结清单。

在Codex中打开这个克隆目录继续开发；GitHub登录用于后续提交，运行软件还需要新电脑自己的生图网站登录，以及可用且已登录的Codex CLI。不要复制旧电脑的虚拟环境、浏览器会话或登录文件。

启动源码界面：

```powershell
.\.venv\Scripts\python.exe main.py
```

选择自行带到新电脑的白底图文件夹，连接已登录的网站。只有用户明确点击开始才提交生图并消耗网站积分和审核额度；安装、冻结检查和控制测试不会提交生图。

直接使用Windows程序时，可从本仓库的 [Releases](https://github.com/wanghua361/soutui-image/releases) 下载当前包，完整解压后运行。它与源码的用途不同：继续开发请使用克隆目录，软件包用于直接操作。跨电脑完整业务仍需在新电脑实际验证。

## 给接手Codex的上下文

先阅读 `AGENTS.md`、`README.md`、`docs/第一阶段流程与审核规则.md`、`docs/分模块开发与验收规范.md`、`docs/本轮审图调整与重新测试.md` 和 `validation/public_handoff/current_state.json`，然后核对 `validation/frozen_modules.json`。

用户确认的关键口径：

- 轻微袖口、领口、裤脚细窄边饰差异可以通过，细小齿、孔或网眼本身不构成明显改款。
- 允许整件衣服一致镜像；拒绝局部口袋、门襟或扣位结构错位。
- 姿势、遮挡、屈腿或裁切导致脚踝不可定位，没有明显改短证据时不单独卡住，结论须如实写定位不足。
- 明显改款、明显短裤和其他可见错误仍拒绝；主要结构实际可见但证据模糊时仍待复核。
- 保留gpt-6.1-sol、账号既有推理设置、原始图片、600秒单次等待、两次独立整图审核和扣位专项。复核与专项并行，只减少独立任务的串行等待。
- 不足三张沿用原参考图补生，每组初轮外最多三轮；日常续跑不能静默清零。
- 每次新版本验证成为当前可用版本后，清除项目内旧程序、旧ZIP、旧源码副本与无用临时文件；验证新版前保留可用版本。

最终规则在少量人工样本上实测：图二通过完整双审和扣位专项，图三因局部结构错误拒绝。118项控制检查通过。其他旧样本按其当时规则登记，不能冒充最终规则重测。没有证明所有商品的准确率不变，也没有承诺固定加速倍数。
