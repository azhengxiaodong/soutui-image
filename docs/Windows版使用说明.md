# 搜推生图 Windows 版使用说明

> 2026-11-03 本地测试版0.2.2、规则2026-11-03.3：允许细窄边饰的小孔、小齿和微小起伏；姿势或裁切导致脚踝不可定位、又无明显改短证据时不单独卡住。允许整件左右镜像，仍拒绝局部口袋/门襟接反和明显改短；独立复核和扣位专项并行。用户要求原批次清空重测，当前状态以 `docs/本轮审图调整与重新测试.md` 及本轮验收报告为准。新规则不自动发布远端，旧批次历史数量不代表本轮结果。

本软件用 Python 编写。Windows 包自带 Python 运行库，整包解压后双击“搜推生图.exe”。当前阶段负责生图、审核及保存；店铺后台上传属于后续阶段。

## 私有更新（0.2.0起）

程序包含固定的私有更新源 `wanghua361/soutui-image-updates` 和校验公钥，不包含GitHub令牌或签名私钥。其他电脑首次使用需配置一次“只读授权”，以后启动或点击“检查规则更新”即可获取已发布版本，不用每次重新接收安装包。

首次配置：在GitHub为这台电脑生成一个细粒度个人访问令牌，仅选该私有仓库，Repository permissions中的Contents设置Read-only。令牌可由仓库维护者按电脑分别生成；目标电脑不必安装Git。点软件里的“只读授权”，输入后会先验证仓库访问，再用Windows DPAPI加密保存在本机。令牌到期或撤销时重新配置。不要把维护端现有写权限令牌当作交付内容。

日常规则更新只下载规则数据，当前商品继续使用已固定版本，新商品采用最新稳定版本；不静默重审全部历史图，不重置补生次数。普通网络失败保留可用本机版本并显示状态。若某版被明确撤销，则相关任务需先升级复核，不能继续放行旧结果。

程序功能更新：先检查更新，再在任务已暂停或结束时点“程序升级”。有新程序时自动下载、验证、关闭旧窗口、替换并重启；旧程序保留为旁边的备份目录。本机运行记录保留。源代码运行时不使用exe替换功能。

本机维护电脑可以沿用已有GitHub凭据；这项本机配置与签名私钥都不会进入交付包。发布端维护说明见项目的 `docs/私有更新维护说明.md`。GitHub负责文件分发，Codex审图仍由每台电脑自己的账号执行。

## 使用前准备

- Windows 10/11 64 位电脑，保持联网。
- 在这台电脑安装可用的 Codex CLI，并用自己的账号登录；软件可沿用 ChatGPT 登录，无须另填模型 API 密钥。账号需有可用模型及额度。
- 在已有 Edge 或 Chrome 浏览器中正常登录 [生图网站](https://ai.51dingxiao.com/app/)，保留一个 MuseFit 生图标签。当前真实浏览器连接验证使用 Edge；不同浏览器版本仍需现场验证。
- 白底图放在一个文件夹顶层，文件名为商品数字 ID，例如 `1083284353580.jpg`。支持 JPEG/PNG，输出子目录不会当作新原图再次导入。
- 当前版本按已确认规格校验：账号收藏中有十七个命名参考组，每组正好五张；从中随机选九组。未分组不参与选择。组数变化时会停止，不把其他数量默认为已支持。

## 操作步骤

1. 将压缩包完整解压。保留“搜推生图.exe”和旁边的 `_internal` 文件夹，不能只发单个 exe。
2. 双击打开，选择白底图文件夹，点击“扫描目录”。商品列表默认全选，可按 Ctrl 选择部分商品。
3. 首次点击“连接当前浏览器账号”。连接只复用已经打开的生图标签，不新开浏览器。连接期间请暂时不要操作目标浏览器或剪贴板；完成后业务通过 HTTP 接口运行。
4. 等到显示网站已连接、Codex 已安装并登录，查看网站当前积分报价。
5. 点击“开始 / 继续”，执行所选商品的九组任务。开始后会使用网站积分：首轮每商品四十五张，补生另计；当前实测均衡 2K 为每张六积分，实际以账号网站当前报价为准。
6. 观察右侧各组进度与下方日志。可以切换同时审核一、二或四张；实际审核时间取决于模型、网络及账号额度。
7. 点击“查看图片目录”查看已保存合格图。

连接现有网页时会暂时使用开发者工具，只读取该网站的当前登录会话，并使用 Windows DPAPI 加密存于本机；不读取密码。遇到浏览器粘贴安全提示会停止，请不要关闭或更改浏览器安全保护来继续。

首次连接若提示“未找到唯一控制台输入框”，请在当前生图标签按 F12，手动选择“控制台 / Console”，确认没有未提交的输入，再重新连接。当前实测使用已有控制台可用的 Edge；其他电脑的默认工具页签及安全提示需要现场验证。

桌面版连接前先独立保存当前剪贴板中的文本和图片等数据，连接后恢复并核对。若提示当前剪贴板对象无法完整保护，请先自行复制一段普通文字再连接；程序在保护失败时不会读取网站会话。

## 生成与审核规则

- 每个商品固定随机选出的九个不同模特组，每组五张参考图。继续运行及补生沿用原计划。
- 固定模特换衣、3:4、2K、立即生成、均衡，每张参考图生成一张。
- 每张成功生成图都与当前原图单独核对。领口、袖口、裤脚、口袋、扣子、颜色、花纹、版型及其他新增/缺失细节都属于检查范围。
- 只核对画面展示部分。裤脚等未入镜的部位不参与这张图的判断。
- 初审认为可通过时，再独立调用同一模型复核一次；两次通过才保存。不通过或可见证据不清的图不进入合格目录。
- 本版明确使用 `gpt-6.1-sol`，规则 `2026-11-03.3`。保留完整十四项、两次独立整图审核及扣位专项，按本说明顶部的轻微边饰/裁切裤长容忍标准执行；明显门襟、口袋、版型及其他改款仍拒绝。
- 当前整轮成功图全部审完后，按组累计内容不同的合格图。每组合格不足三张时，用该组原五张参考图补生，初次之外最多三轮；仍不足就暂停该组并提示，其他组继续。
- 达标轮次中通过的其他图片也保留，不截断为三张。

模型审核仍可能漏判或误判；双次检查降低风险，不能保证零错误。用户示例校准与实际任务结果见项目验收记录，不能把少量示例说成对所有款式的准确率证明。

## 升级后复核旧图片

选择原白底图文件夹、使用原来的本机记录目录，点击“复核旧图片”。这个操作只调用 Codex 复核已有图片，不提交新生成，无须先连接网站。界面显示“旧图待复核”时，旧数量不再算作当前合格。

旧图片会先按原字节保留在本机运行记录目录的 `quality_withdrawn` 中。整款复核完成后，按新版通过的图片恢复到原商品的九组目录；期间九组目录暂时为空可能是正常复核状态。不要删除本机记录或待复核区。通过数量不足三张时显示“待补生”，但本按钮不会自动补生。

需要实际补生时再连接网站，点击“开始 / 继续”；这会使用网站积分，并沿用原任务记录和补生次数，不清零上限。额度或网络不足时保留已完成审核阶段，恢复后点击“复核旧图片”继续。

新增规则已用用户两张错误图和一张认可局部图实际校准，但细微扣位凸片的单独诊断仍不稳定，建议抽查最终留图。不能将模型未发现错误理解为保证服装完全一致。

## 保存位置

```text
白底图文件夹/
├── 1083284353580.jpg
└── 1083284353580/
    ├── 组01/
    ├── 组02/
    ├── …
    └── 组09/
```

图片按网站下载的原始字节保存，文件名包含轮次、参考图序号与内容哈希。商品目录中的 `.搜推生图.json` 和 `.soutui.lock` 是记录文件，请保留。

## 暂停、恢复及常见问题

- 点击“暂停新任务”后，已开始的模型检查可能需要先结束；网站已提交的任务会保留。不要用强制关闭代替正常暂停。
- 继续时使用同一白底图目录及本机任务记录，复用已有生成任务、审核结论与合格图，避免重复提交。提交状态不明时程序先查回原任务，不盲目重发。
- “补生上限，待处理”表示该组已用完三轮补生，合格图仍保留。重复开始不会自动清空次数或重新抽组。
- 网络或模型调用失败时保留记录。恢复网络/账号后重新继续；已审完的缓存可复用。可见细节不清的待复核图不会自动放行。
- 登录过期时，在浏览器正常重新登录后，再点“连接当前浏览器账号”。不把密码或令牌发到聊天窗口。
- 提示已有流程运行时，回到原窗口处理；同一个数据目录只允许一个流程。
- 提示原图、参考组或输出目录不符时，先保留现场及记录，不删除记录来强行重跑。

Windows 版的运行记录默认在 `%LOCALAPPDATA%\搜推生图`。这里包含任务计划、审核缓存、进度与本机加密会话；清空或更换记录目录可能丢失续跑依据。软件升级时保留它。源代码开发入口默认使用项目下的 `data`，与 Windows 版的默认目录不同。

## 发给其他电脑

发送完整交付压缩包。每台电脑自行正常登录有权使用的生图账号和 Codex 账号，首次重新连接该电脑的浏览器；生图账号需具备上述十七组收藏配置。不发送开发机的 `data`、账号会话、审核缓存或原图。

当前安装包已在开发电脑验证。另一台真实电脑的安装、浏览器版本兼容及完整生图审核流程，需要在该目标电脑上另行验收，不能将本机 exe 启动验证称为跨电脑验收。

如果 Codex 不在自动发现的位置，可以使用进程环境变量 `SOUTUI_CODEX_EXE` 指定已有 Codex 可执行文件完整路径。软件不会携带或安装其他人的 Codex 登录凭据。

## 开发与诊断

从源码运行桌面界面：`python main.py`；只扫描输入：`python main.py --input "白底图目录"`；真正执行需明确增加 `--run`。

构建：`python tools/build_windows.py`。构建用版本见 `requirements-build.txt`；运行源码依赖见 `pyproject.toml`。

exe 支持 `--self-test --data-dir "诊断输出目录"`，写出依赖自检 JSON，不联网、不生成。`--connect-existing` 只连接现有网站会话并读取收藏，不生成；诊断文件包含状态，不回显令牌。

`--input "白底图目录" --data-dir "原运行记录目录" --recheck-saved` 只复核旧图片；默认使用 Sol，不新增生图。
